# Cover Maker
by [@jaamiparvez](https://jaamiparvez.com/)

Preview a live version here https://jaamiparvez.com/projects/covermaker

## Overview 


Cover Maker is a browser-based tool for creating simple eBook covers. Users can choose a solid-colour, gradient, or image background and customize the author and title text by changing the colour, font size, font style, text stroke, and text shadow. The application uses Next.js, Tailwind CSS, and Fabric.js to provide an interactive cover-editing experience.

![Alt text](/public/screenshot2.png?raw=true "Screenshot of live project")


## Built With

[Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), [Fabric.js](http://fabricjs.com/)

## Features

- Cover Maker lets you alter the background colour of the cover to a solid, gradient or an image.
- Cover Maker also allows you to customize the text properties for the author's name and title by changing the text colour, font size, and text style, as well as the text stroke and text shadow.
